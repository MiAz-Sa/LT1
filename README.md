# Circular Garden Calculator.
### This calculates the area, circumference, the square root of the area, the area rounded down, and area rounded up.

#### To run you run the code, then input the radius, (Said in prompt)
#  
### Sample Output:
#### input:
##### radius = 12
#### output:
##### Your area is 452.3893421169302
##### Your circumference is 75.39822368615503
##### The square root of the area is 21.269446210866192
##### The area rounded down is 453
##### The area rounded down is 452
